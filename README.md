# ChatMirror

Privacy-first browser-only chat analysis MVP.

## Features
- Import WhatsApp TXT and Telegram JSON exports
- Show message counts and participant share
- Highlight expressions of thanks, apologies, feelings, generalizations and proposals with source quotes
- Synthetic demo data

## Privacy
All parsing and analysis runs in the browser. No chat content is uploaded, stored on GitHub or sent to an AI provider. Only analyze conversations you are authorized to use.

## Limitations
This is a rule-based MVP, **not** AI-based psychological analysis. WhatsApp exports vary by language and device; not every date/time format is supported. Quotes are observations, not diagnoses or judgments.

## Deploy
GitHub repository Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
